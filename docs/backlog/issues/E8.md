## Objectif

Garantir par des tests automatisés que chaque critère d'acceptation et chaque invariant de sécurité est vérifié, avant et après déploiement.

## Périmètre

- Stratégie de test et matrice de traçabilité AC ↔ tests.
- Tests unitaires IaC (`tofu test` avec provider simulé).
- Tests smoke et sécurité post-déploiement (Hurl), performance (k6), E2E (Playwright), DAST (OWASP ZAP).

## Issues enfants

- EN-81 — Stratégie de test et matrice de traçabilité
- EN-82 — Socle de tests unitaires IaC (`tofu test`, provider simulé)
- EN-83 — Tests smoke et sécurité post-déploiement (Hurl : 401/403, BOLA, upload, WAF)
- EN-84 — Performance k6 (exigence < 2 s : p95 < 2000 ms)
- EN-85 — E2E Playwright des parcours critiques
- EN-86 — DAST : scan de base OWASP ZAP (nocturne, dev)

## Critères de sortie

- [ ] Chaque AC `must` est relié à au moins un test automatisé dans la matrice.
- [ ] Les smoke tests et tests de sécurité tournent après chaque déploiement en dev et bloquent la promotion en cas d'échec.
- [ ] Les issues `must` sont fermées.
