## Contexte

Le workshop dispose d'un budget limité. Une alerte de coût prévient l'équipe avant un dépassement.

## User story

En tant qu'équipe OPS, je veux un budget AWS avec alertes, afin de détecter toute dérive de coût au plus tôt.

## Critères d'acceptation

```gherkin
# language: fr
Fonctionnalité: EN-16 — Budget et alertes de coût

  Scénario: AC1 — Budget mensuel
    Étant donné la variable de montant mensuel
    Quand le plan est calculé
    Alors un budget de coût mensuel est créé, filtré sur les tags du projet si possible

  Scénario: AC2 — Seuils d'alerte
    Étant donné le budget
    Quand le coût réel ou prévisionnel dépasse les seuils configurés (par exemple 50 %, 80 %, 100 %)
    Alors une notification est envoyée aux destinataires configurés

  Scénario: AC3 — Validation
    Étant donné un montant nul ou négatif
    Quand le plan est calculé
    Alors la validation de variable échoue
```

## Exigences non fonctionnelles

- Les adresses destinataires sont des variables, pas des valeurs codées en dur.
