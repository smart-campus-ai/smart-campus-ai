## Contexte

L'issue d'origine prévoyait un Lambda authorizer. **Correction** : l'architecture v3 retient l'authorizer Cognito User Pool natif de l'API REST. Il valide signature, expiration, émetteur et audience, sans code, sans démarrage à froid et avec une surface d'attaque réduite. Les tokens émis par Cognito couvrent aussi les utilisateurs fédérés Entra ID. Les groupes sont lus depuis `cognito:groups`.

## User story

En tant qu'architecte sécurité, je veux que l'API REST valide les tokens via l'authorizer Cognito natif, afin de sécuriser l'accès aux routes protégées.

## Critères d'acceptation

```gherkin
# language: fr
Fonctionnalité: EN-32 — Authorizer Cognito natif

  Scénario: AC1 — Authorizer attaché à toutes les méthodes protégées
    Étant donné l'API REST
    Quand le plan est calculé
    Alors un authorizer de type COGNITO_USER_POOLS référence le user pool
    Et toutes les méthodes sauf celles déclarées publiques utilisent cet authorizer
    Et aucun authorizer de type Lambda n'existe

  Scénario: AC2 — Requête sans token
    Étant donné une méthode protégée
    Quand elle est appelée sans en-tête "Authorization"
    Alors la réponse est 401

  Scénario: AC3 — Token invalide ou expiré
    Étant donné un token altéré, expiré ou émis par un autre user pool
    Quand une méthode protégée est appelée avec ce token
    Alors la réponse est 401

  Scénario: AC4 — Groupes transmis au handler
    Étant donné un token valide d'un membre du groupe "admin"
    Quand une méthode est appelée
    Alors le handler reçoit "cognito:groups" et le "sub" dans le contexte de l'authorizer

  Scénario: AC5 — Méthodes admin
    Étant donné un token valide du groupe "student"
    Quand une méthode réservée aux admins est appelée
    Alors la réponse est 403
```

## Exigences non fonctionnelles

- Les tokens ne sont jamais journalisés (logs d'accès sans en-tête `Authorization`).

## Notes techniques / décisions

- Décision documentée dans l'ADR « authorizer Cognito natif » (EN-91).
- AC5 est vérifié dans les handlers (contrôle de `cognito:groups`) ; AC2, AC3, AC5 sont rejoués par les tests de sécurité EN-83.
