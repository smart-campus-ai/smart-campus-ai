## Contexte

Le chatbot ne doit répondre qu'à partir des sources indexées pour éviter les réponses hors contexte ou inventées. Le Guardrail Bedrock applique une vérification d'ancrage contextuel avec des seuils ; sous le seuil, l'assistant refuse et propose un ticket.

## User story

En tant que responsable de la sécurité, je veux que le chatbot RAG s'appuie exclusivement sur les sources indexées, afin d'éviter les réponses hors contexte ou erronées.

## Critères d'acceptation

```gherkin
# language: fr
Fonctionnalité: RF03 — Confinement RAG

  Scénario: AC1 — Utilisation exclusive de la Knowledge Base
    Étant donné une question d'étudiant
    Quand le chatbot construit sa réponse
    Alors il s'appuie uniquement sur les passages récupérés dans la Knowledge Base Bedrock

  Scénario: AC2 — Vérification d'ancrage avec seuils
    Étant donné le Guardrail associé au chatbot
    Quand une réponse est générée
    Alors la vérification d'ancrage contextuel et de pertinence est appliquée avec les seuils configurés

  Scénario: AC3 — Sous le seuil : refus et proposition de ticket
    Étant donné une réponse dont le score d'ancrage est inférieur au seuil
    Quand le Guardrail l'évalue
    Alors l'étudiant reçoit "je ne sais pas"
    Et l'interface propose de créer un ticket (US10)

  Scénario: AC4 — Hors sujet et injection de prompt
    Étant donné une question relevant d'un sujet interdit ou une tentative d'injection de prompt
    Quand elle est soumise
    Alors le Guardrail la bloque et une réponse neutre est renvoyée

  Scénario: AC5 — Seuils paramétrables
    Étant donné les variables de seuil du module
    Quand une valeur hors de l'intervalle [0, 1] est fournie
    Alors la validation de variable échoue
```

## Exigences non fonctionnelles

- Les blocages du Guardrail sont comptés (métriques) sans journaliser le contenu des échanges.
- Inférence dans l'UE.

## Notes techniques / décisions

- Seuils initiaux à calibrer sur un jeu de questions de démo (EN-95) ; valeurs consignées dans un ADR ou dans l'issue.
- Le Guardrail est fourni par EN-52 ; la logique de repli est dans la fonction `chat`.
