## Contexte

CloudFront est le point d'entrée unique des utilisateurs, servi sur l'URL `*.cloudfront.net` (pas de domaine, décision du 22/10). La SPA est dans un bucket S3 privé accessible uniquement via OAC ; `/api/*` est routé vers l'API REST sur la même origine, ce qui supprime le besoin de CORS. La redirection HTTPS, auparavant dans #21, est portée ici.

## User story

En tant qu'équipe OPS, je veux héberger le front sur S3 et CloudFront avec OAC et des en-têtes de sécurité, afin de servir la SPA rapidement et sans exposer le bucket.

## Critères d'acceptation

```gherkin
# language: fr
Fonctionnalité: EN-21 — Hébergement S3/CloudFront

  Scénario: AC1 — Bucket privé, accès via OAC uniquement
    Étant donné le bucket de la SPA
    Quand le plan est calculé
    Alors Block Public Access est entièrement activé, l'ownership est "BucketOwnerEnforced"
    Et la politique du bucket n'autorise la lecture qu'au principal CloudFront avec une condition sur l'ARN de la distribution
    Et elle refuse toute requête sans "aws:SecureTransport"

  Scénario: AC2 — Redirection HTTPS et TLS
    Étant donné la distribution
    Quand un client appelle l'URL en HTTP
    Alors il est redirigé vers HTTPS
    Et la politique TLS minimale est "TLSv1.2_2021"

  Scénario: AC3 — En-têtes de sécurité
    Étant donné une réponse de la distribution
    Quand on inspecte les en-têtes
    Alors HSTS, Content-Security-Policy (frame-ancestors 'none'), X-Content-Type-Options: nosniff et Referrer-Policy sont présents

  Scénario: AC4 — Comportement /api/*
    Étant donné le comportement "/api/*"
    Quand le plan est calculé
    Alors il cible l'origine API Gateway avec le cache désactivé
    Et l'en-tête "Authorization" est transmis par une origin request policy

  Scénario: AC5 — Accès direct au bucket refusé
    Étant donné l'URL S3 directe d'un objet de la SPA
    Quand un client la demande
    Alors il reçoit un refus
```

## Exigences non fonctionnelles

- Bucket chiffré par CMK, versionné, avec cycle de vie.
- Logs d'accès chiffrés, rétention définie.

## Notes techniques / décisions

- Module `edge` : variables pour l'origine API et la web ACL CLOUDFRONT (RF04) ; `enable_custom_domain=false` (EN-22).
- Le contenu de la CSP est aligné avec SE (sources du SPA, endpoint Cognito).
- Une `check` OpenTofu peut vérifier le statut de la distribution et la redirection HTTPS après apply.
