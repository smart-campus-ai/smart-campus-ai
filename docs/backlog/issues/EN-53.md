## Contexte

Les historiques de chat (US02) ont une rétention différente des tickets ; ils sont donc dans une table séparée `chat-sessions` avec un attribut TTL pour la purge RGPD (US08).

## User story

En tant qu'équipe OPS, je veux une table `chat-sessions` avec TTL, afin que les historiques de conversation soient conservés le temps nécessaire puis purgés automatiquement.
