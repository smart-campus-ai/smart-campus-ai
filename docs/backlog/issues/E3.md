## Objectif

Authentifier les étudiants et les administrateurs et exposer une API REST protégée, validée et observable.

## Périmètre

- Cognito User Pool : groupes `student`/`admin`, client SPA authorization code + PKCE, MFA admin, utilisateurs de test en dev.
- Authorizer Cognito User Pool natif sur l'API REST (pas de Lambda authorizer).
- API REST régionale : ressources/méthodes, validation des requêtes par modèles JSON Schema, throttling, logs d'accès JSON, X-Ray.
- Fédération Microsoft Entra ID (optionnelle, derrière `enable_entra_federation`).

## Issues enfants

- EN-31 — Cognito : user pool, groupes, client PKCE, MFA admin, utilisateurs de test (dev)
- EN-32 — Validation des tokens par l'authorizer Cognito de l'API REST
- EN-33 — API REST régionale : ressources/méthodes, validation, throttling, logs d'accès JSON, X-Ray
- US06 — Authentification unifiée SSO Microsoft

## Critères de sortie

- [ ] Un utilisateur de test se connecte depuis la SPA via le flux PKCE et appelle l'API avec son token.
- [ ] Toute requête sans token ou avec un token invalide reçoit un 401 ; une méthode admin appelée par un étudiant reçoit un 403.
- [ ] Les requêtes non conformes au modèle JSON Schema sont rejetées par API Gateway (400).
- [ ] EN-31, EN-32, EN-33 sont fermées ; US06 est livrée ou explicitement reportée.
