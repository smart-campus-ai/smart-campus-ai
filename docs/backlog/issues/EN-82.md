## Contexte

Chaque module OpenTofu doit prouver ses invariants de sécurité sans compte AWS, via `tofu test` avec un provider simulé (`mock_provider "aws"`, `command = plan`). Ce socle fournit les conventions et exemples réutilisés par tous les modules.

## User story

En tant que QE, je veux un socle de tests unitaires IaC, afin que chaque module vérifie ses invariants de sécurité à chaque PR, sans accès AWS.

## Critères d'acceptation

```gherkin
# language: fr
Fonctionnalité: EN-82 — Tests unitaires IaC

  Scénario: AC1 — Exécution sans AWS
    Étant donné un module avec "tests/unit.tftest.hcl"
    Quand "task test:unit" s'exécute sans identifiants AWS
    Alors les tests passent grâce à "mock_provider"

  Scénario: AC2 — Invariants de référence
    Étant donné le guide de tests
    Quand on le consulte
    Alors il fournit des exemples d'assertions : BPA du bucket, rotation KMS, Lambda arm64, rétention des logs, absence d'action wildcard, WAF attaché, politique TLS

  Scénario: AC3 — Validations de variables
    Étant donné une variable validée
    Quand un test fournit une valeur invalide
    Alors il utilise "expect_failures" et vérifie l'échec

  Scénario: AC4 — Intégré au gate
    Étant donné "task check" et la CI (EN-71)
    Quand un test unitaire échoue
    Alors le gate échoue

  Scénario: AC5 — Tests d'intégration à la demande
    Étant donné "tests/integration.tftest.hcl"
    Quand "task test:integration ENV=dev" est lancé
    Alors il applique puis détruit le module dans le compte dev
```

## Exigences non fonctionnelles

- Durée des tests unitaires < 2 minutes pour l'ensemble des modules.
