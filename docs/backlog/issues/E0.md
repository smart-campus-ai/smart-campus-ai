## Objectif

Doter le dépôt d'un outillage reproductible et d'une gouvernance GitHub stricte, pour que chaque changement passe par une PR contrôlée, tracée et sûre.

## Périmètre

- Chaîne d'outils épinglée (mise), tâches communes (Taskfile), hooks git (lefthook), commitlint, editorconfig.
- Gouvernance GitHub : rulesets `develop`/`main`, labels, templates d'issue et de PR, CODEOWNERS, environnements `dev`/`prod`, board GitHub Projects.
- Chaîne d'approvisionnement : Renovate, actions épinglées par SHA, secret scanning et push protection.

Hors périmètre : les workflows CI eux-mêmes (E7).

## Issues enfants

- EN-01 — Outillage du dépôt : mise, Taskfile, lefthook, commitlint, editorconfig
- EN-02 — Gouvernance GitHub : rulesets, labels, templates, CODEOWNERS, environnements, board Projects
- EN-03 — Chaîne d'approvisionnement : Renovate, actions épinglées par SHA, secret scanning et push protection

## Critères de sortie

- [ ] `task setup` installe la chaîne d'outils épinglée et les hooks sur un poste neuf.
- [ ] `develop` et `main` sont protégées par des rulesets avec checks requis ; aucun push direct possible.
- [ ] La taxonomie de labels, les templates et le board sont en place et utilisés par toutes les issues.
- [ ] Secret scanning, push protection et Renovate sont actifs.
- [ ] Toutes les issues enfants sont fermées.
