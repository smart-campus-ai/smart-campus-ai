## Objectif

Détecter et diagnostiquer rapidement les incidents : logs structurés centralisés, traces, tableau de bord et alarmes notifiées.

## Périmètre

- Logs JSON structurés (Lambda, API Gateway, WAF) dans CloudWatch, chiffrés KMS, rétention définie.
- Traces X-Ray, tableau de bord CloudWatch.
- Alarmes : 5xx, latence p95, throttles, profondeur des DLQ, blocages WAF, erreurs Lambda, erreurs d'authentification → SNS.
